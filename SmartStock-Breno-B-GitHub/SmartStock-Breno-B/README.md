## Sobre o projeto
O SmartStock é uma plataforma web planejada para ajudar empresas a gerenciar produtos, entradas e saídas de estoque, níveis mínimos, relatórios e indicadores operacionais. Em uma etapa futura, o sistema poderá integrar Inteligência Artificial e automações com n8n.

## Funcionalidades previstas
- Cadastro, consulta, atualização e exclusão de produtos (CRUD).
- Registro de entradas e saídas.
- Atualização automática das quantidades.
- Definição de estoque mínimo e alertas de reposição.
- Dashboard com indicadores.
- Relatórios e histórico de movimentações.
- Preparação para integração futura com IA e n8n.
